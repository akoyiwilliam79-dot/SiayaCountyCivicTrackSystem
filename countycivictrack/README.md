# Civic System

A Django-based civic engagement platform designed to help communities report issues, share updates, and track public service improvements.

## Features
- Report civic issues (roads, waste, lighting, etc.)
- Track issue status and updates
- User authentication system
- Admin dashboard for managing reports
- Activity logging system

## Tech Stack
- Python
- Django
- SQLite (development)
- HTML/CSS templates
- Python logging

## Project Structure
- `manage.py` → Django entry point
- `settings.py` → project configuration
- apps → core functionality modules
